# Padel Smash

A modern, responsive website concept for **Padel Smash**, designed to showcase padel tournaments, events, players, schedules, results, and tournament information.

## Overview

**Padel Smash** is a frontend web project created for a padel tournament/event platform in Baku.

The website provides an organized and engaging experience for visitors who want to discover upcoming tournaments, learn about events, view tournament information, and explore the world of padel.

The project focuses on **modern UI/UX, responsive design, visual storytelling, and interactive frontend development**.

## Features

* Fully responsive design
* Modern sports-focused UI
* Hero section with tournament branding
* Upcoming tournaments section
* Tournament dates and locations
* Tournament information
* Player / team sections
* Tournament results
* Event gallery
* Registration / participation section
* Contact information
* Smooth animations and transitions
* Responsive navigation
* SVG-based icons
* Mobile, tablet, and desktop optimization

## Technologies

* **HTML5** — semantic structure
* **CSS3** — responsive layouts, animations, and styling
* **JavaScript** — interactions and dynamic functionality
* **SVG** — icons and interface elements

## Website Sections

### Home

A visually focused landing page introducing Padel Smash and highlighting the main tournament or upcoming events.

### Tournaments

Displays information about tournaments, including:

* Tournament name
* Date
* Location
* Category
* Status
* Registration information

### Players & Teams

A dedicated area for presenting participating players or teams.

### Results

Tournament results and rankings can be displayed in an organized format.

### Gallery

A visual gallery for tournament photos, matches, players, and event highlights.

### Registration

A dedicated section where visitors can find information about participating in upcoming tournaments.

## Responsive Design

The website is designed to work across multiple devices:

* Desktop
* Laptop
* Tablet
* Mobile

Navigation, cards, tournament information, galleries, and other components automatically adapt to different screen sizes.

## Design Approach

The design combines a **sporty, energetic, and modern visual style** with a clean interface.

Key principles include:

* Strong typography
* Clear visual hierarchy
* Large photography
* Modern cards
* Generous spacing
* Smooth animations
* Responsive layouts
* Minimal interface elements
* SVG icons instead of emojis

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Padel-Smash.git
```

Navigate to the project:

```bash
cd Padel-Smash
```

Open `index.html` in your browser.

No external framework or build system is required.
